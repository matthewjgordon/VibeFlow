# Architecture reviews

Store dated architecture assessments here. Separate observations, evidence,
current risks, future pressure, unresolved questions, and recommendations.
Keep severity distinct from urgency and recommendations proportional to
demonstrated architectural pressure.

Use `YYYY-MM-DD <Subject> Review.md`; the architecture-health skill uses
`YYYY-MM-DD Architecture Health Review.md`. A review captures a point in time
and does not authorize implementation or a redesign. Reconcile durable
[wiki explanations](../wiki/01%20Home.md) when verified implementation changes
make them stale.

Add links to actual reviews here as they are written. None exist in this starter.

# Active workstreams

Keep each current workstream in its own readable folder. Create only artifacts
the work needs; the complete chain is most useful for substantial capabilities.

```text
<Workstream Name>/
├── <Workstream Name>.md
├── <Workstream Name> PRD.md
├── <Workstream Name> Issues.md
└── Slice Validation.md (when work-specific validation is needed)
```

These artifacts record decisions and implementation intent. They do not prove
the work is implemented. Link the durable [implementation report](../implementation-reports/README.md)
and affected [wiki pages](../wiki/01%20Home.md) as evidence becomes available.
The canonical report is maintained in the separately documented report area.

Add links to actual workstreams here as they are created. None exist in this
starter. Preserve useful planning history or retire it deliberately; no fixed
archive/deletion process or tracker state is prescribed.
